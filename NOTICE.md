# Provenance and Scope

The first collection contains 54 generic kitchen and ingredient illustrations,
generated with the built-in OpenAI image-generation tool and reviewed by the
project contributors. The images are not hand-drawn, vector files, photographs
of actual branded products, or cooking/safety instructions.

The shared visual direction uses coral and mint accents, realistic food,
brushed steel and light wood, with soft upper-left lighting. Source atlases,
generation prompts and deterministic export code are retained in the repository.
PNG and WebP exports preserve transparency and use a 512 x 512 pixel canvas.
Some exports are upscaled from the source atlas cells; 512 pixels is the canvas
size, not a claim of native 512-pixel detail per object.

CC0 applies only to rights the contributor may hold. AI output may receive
different legal treatment in different jurisdictions. No guarantee of
uniqueness, third-party clearance, fitness or accuracy is made. Please report
visual defects or rights concerns through repository issues.

Scrappy Chef's logo, wordmarks, app code, account information and provider keys
are deliberately excluded. Their use is not authorized by this repository.

The package has no runtime dependencies and no installation lifecycle scripts.
Maintainer tooling uses Sharp for cropping, alpha-preserving resizing, format
conversion and preview sheets, not for generating new artwork.
